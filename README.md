# Hello World (PHP)

This repo is a simple Git learning sandbox and a PHP script demo.

## Usage

```bash
php hello-world.php
```

## Harness Engineering Files

- `AGENTS.md`: agent execution contract and contribution rules.
- `docs/architecture.md`: current repository structure and design principles.
- `docs/api-contract.md`: runtime command/output contract.
- `docs/domain-rules.md`: repository intent and content constraints.
- `plans/TASK_TEMPLATE.md`: reusable task planning template.
